# CodeAlpha Hangman Game

## Project Description
This is a simple text-based Hangman Game developed using Python. The player guesses letters to identify a hidden word. The game allows a maximum of 6 incorrect guesses.

## Features
- Random word selection
- Letter guessing system
- 6 incorrect guess limit
- Console-based gameplay

## Technologies Used
- Python
- Random Module

## How to Run
1. Install Python
2. Open terminal
3. Run the file:

```bash
python hangman.py
